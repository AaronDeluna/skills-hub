# Сабагенты для ревью крупной области (опционально)

Нужно только на Шаге 3 (сбор черновых замечаний) и только когда область ревью большая -
каталог или модуль с многими файлами. Для одного-двух файлов сабагенты не нужны: читаешь сам.

Зачем: прочитать десятки файлов самому - это много контекста и потеря деталей. Разложи
чтение по сабагентам: каждый ревьюит свой пакет файлов и возвращает короткий список
кандидатов по фиксированному шаблону. Сам ты только собираешь их и идёшь дальше.

Важно: сабагенты применяются ТОЛЬКО к фазе чтения/поиска кандидатов. Написание и **прогон
тестов** (Шаги 4-5) делай сам, последовательно - параллельные прогоны в одном модуле мешают
друг другу (общая сборка), и статусы легко перепутать.

## Сколько сабагентов

Если инструмент сабагентов (Task/Agent) доступен и файлов много:
```
число сабагентов = min(4, число файлов боевого кода в области)
```
Раздели файлы ровными непересекающимися пакетами, чтобы вместе покрыть ВСЕ файлы. Если
сабагентов нет - читай сам, последовательно.

## Промпт сабагенту (копируй дословно, подставь <...>)

```
Ты ревьюишь СПИСОК файлов и только собираешь КАНДИДАТОВ в замечания. Не доказывай, не пиши
тесты, не меняй файлы. Верни ТОЛЬКО список по шаблону, без рассуждений.

Файлы для ревью (каждый прочитай целиком): <список путей>
На что смотреть (категории): логика/вычисления, null, границы и пустые данные, коллекции и
стримы, конкурентность, ресурсы и утечки, обработка исключений, контракты/API, числа-даты-
строки, состояние и жизненный цикл. Не оценивай стиль как баг.

Для каждого подозрительного места верни строку РОВНО так:
КАТЕГОРИЯ | файл:строка | что подозрительно (1 фраза) | как это проверить тестом (1 фраза) | проверяемо тестом: да/нет

Если в файле ничего не нашёл - строкой: <файл>: чисто.
```

## Что делать с результатами

- Сложи все строки в свой файл заметок, присвой сквозные ID и статус «проверяемо тестом».
- Дальше сам, по Шагу 4, пишешь и прогоняешь тесты по каждому проверяемому кандидату.
- Дубли между пакетами схлопни; явный мусор отбрось (но лучше проверить тестом, чем молча
  выкинуть).
