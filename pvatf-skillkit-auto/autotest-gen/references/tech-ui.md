# Справка: ui (Playwright, Selenide)

Для агента `pvatf-generator`. Библиотека - из задания («библиотека UI»); `-` или обе ->
Playwright, если в проекте нет классов страниц на Selenide. Имена фрейма - только из конспекта
`D-ui-<n>` или кода проекта.

## Где брать локаторы - строго по порядку

1. Класс страницы (PageObject) уже есть в проекте и в нём есть нужный элемент -> вызов его метода.
2. В инструментах агента есть браузерный MCP (например chrome-devtools) и в ТК или
   настройках есть адрес страницы -> открой страницу и сними DOM (таймаут каждого вызова -
   120 секунд; таймаут или ошибка -> повтори 1 раз, снова -> шаг `blocked`, причина «браузер
   не открыл <адрес>»). Локатор по приоритету:
   `data-testid` > `id` > `name` > `aria-label` / роль с именем > текст. XPath по позиции - нельзя.
3. Ни того, ни другого -> шаг `blocked`, «Нужно из документации: -», причина «нет локатора
   для <элемент>: нужен адрес страницы или PageObject».

## Как писать

1. Один экран - один класс страницы `<Экран>Page` в пакете `<пакет теста без последней части>.pages`.
   Элементы - приватные поля, действия - публичные методы, возвращают страницу (цепочка).
2. Текст на кнопках и полях из ТК («Восстановить доступ») - аргумент локатора внутри класса
   страницы, а не константа теста.
3. Метод чтения текста элемента защищён от пустого элемента: нет текста -> пустая строка, не
   `NullPointerException`.
4. Проверка видимости и текста - matchers/условия фрейма из конспекта (`should`-проверки
   элемента или `assertIsDisplayed` элемента фрейма), не JUnit.
5. Переход на новый экран - новый G (это делает план); первый шаг G - ожидание загрузки
   страницы методом страницы.

## Нельзя -> нужно

- Нельзя: `page.locator("//div[3]/button[2]").click()`. Нужно: `loginPage.clickSubmit()`, внутри - локатор по `data-testid`.
- Нельзя: `assertEquals("Добро пожаловать", page.textContent("h1"))`. Нужно: проверка элемента matcher фрейма из конспекта.

## Пример фрагмента (имена - условные, проверь по конспекту и проекту)

```java
// Шаг 1: Открыть страницу входа
LoginPage loginPage = loginSteps.openLoginPage();
// Шаг 2: Ввести логин и пароль пользователя из данных теста
loginPage.enterLogin(userLogin).enterPassword(userPassword).clickSubmit();
```
