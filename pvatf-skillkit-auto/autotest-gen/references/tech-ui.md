# Справка: ui (Playwright, Selenide)

Для агента `pvatf-generator`. Библиотека - из задания («библиотека UI»); `-` или обе ->
Playwright, если в проекте нет классов страниц на Selenide. Имена фрейма - только из конспекта
`D-ui-<n>` или кода проекта.

## Где брать локаторы - строго по порядку

1. Класс страницы (PageObject) уже есть в проекте и в нём есть нужный элемент -> вызов его метода.
2. В инструментах агента есть Frap MCP (`frap_snapshot_script`, `frap_build_element_map`,
   `frap_generate_page_object`), браузерный MCP (chrome-devtools: `new_page`, `navigate_page`,
   `evaluate_script`) и в ТК или настройках есть адрес страницы -> класс страницы строит Frap,
   раздел «Класс страницы через Frap» ниже. Не вышло -> пункт 3.
3. В инструментах агента есть браузерный MCP (например chrome-devtools) и в ТК или
   настройках есть адрес страницы -> открой страницу и сними DOM (таймаут каждого вызова -
   120 секунд; таймаут или ошибка -> повтори 1 раз, снова -> шаг `blocked`, причина «браузер
   не открыл <адрес>»). Локатор по приоритету:
   `data-testid` > `id` > `name` > `aria-label` / роль с именем > текст. XPath по позиции - нельзя.
4. Ничего из этого -> шаг `blocked`, «Нужно из документации: -», причина «нет локатора
   для <элемент>: нужен адрес страницы или PageObject».

## Класс страницы через Frap

Таймаут каждого вызова MCP - 120 секунд; таймаут или ошибка -> повтори 1 раз, снова -> пункт 3
раздела «Где брать локаторы», в «Причина» фрагмента: «Frap: <вызов> - <ошибка>».

1. Открой страницу: `new_page` с адресом (страница уже открыта - `navigate_page`).
2. `frap_snapshot_script` -> скрипт снимка. В скрипте есть `async` или `await` -> оберни его в
   синхронную функцию `() => { ... }` без `async/await`: `evaluate_script` ждёт синхронный код.
3. `evaluate_script` со скриптом -> снимок DOM.
4. В шагах этого G есть переходы на другой экран (клик, отправка формы) -> выполни действие в
   браузере (`click` / `fill` по снимку `take_snapshot`), подожди 500 мс и сними DOM снова (пункты
   2-3). Не больше 10 снимков на G. Снимок совпал с прошлым - не используй его.
5. По каждому снимку: `frap_build_element_map` (снимок) -> путь к карте элементов;
   `frap_generate_page_object` (путь к карте, язык `java_playwright` или `java_selenide` - по
   библиотеке UI задания, имя `<Экран>Page`, пакет `<пакет теста без последней части>.pages`).
6. Файлы из ответа перенеси в `src/test/java/<путь пакета pages>/`, не в `src/main`. Класс с
   таким именем уже есть -> не перезаписывай, добавь в него только недостающие элементы.
7. Для каждой проверки текста в ожидаемом результате шага («отображается заголовок "..."»,
   «содержит текст "..."») в классе страницы есть метод `get<Элемент>Text()` с защитой от
   пустого элемента (правило 3 раздела «Как писать»). Frap такого метода не дал -> допиши метод сам.
8. Закрой страницу. В «Файлы шагов» фрагмента перечисли классы страниц.

## Как писать

1. Один экран - один класс страницы `<Экран>Page` в пакете `<пакет теста без последней части>.pages`.
   Элементы - приватные поля, действия - публичные методы, возвращают страницу (цепочка).
2. Текст на кнопках и полях из ТК («Восстановить доступ») - аргумент локатора внутри класса
   страницы, а не константа теста.
3. Метод чтения текста элемента защищён от пустого элемента: нет текста -> пустая строка, не
   `NullPointerException`.
4. Проверка видимости и текста - matchers/условия фрейма из конспекта (`should`-проверки
   элемента или `assertIsDisplayed` элемента фрейма), не JUnit.
5. Переход на новый экран - новый G (это делает план); первый шаг G - ожидание загрузки
   страницы методом страницы.

## Нельзя -> нужно

- Нельзя: `page.locator("//div[3]/button[2]").click()`. Нужно: `loginPage.clickSubmit()`, внутри - локатор по `data-testid`.
- Нельзя: `assertEquals("Добро пожаловать", page.textContent("h1"))`. Нужно: проверка элемента matcher фрейма из конспекта.

## Пример фрагмента (имена - условные, проверь по конспекту и проекту)

```java
// Шаг 1: Открыть страницу входа
LoginPage loginPage = loginSteps.openLoginPage();
// Шаг 2: Ввести логин и пароль пользователя из данных теста
loginPage.enterLogin(userLogin).enterPassword(userPassword).clickSubmit();
```
