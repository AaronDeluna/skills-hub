# Оркестратор набора PVATF (автономная версия)

Набор ведёт два процесса, состояние каждого - в файлах `.gigacode/data/`: миграция
(`migration/`), окружение и генерация автотестов (`autotest/`). Ты сам не мигрируешь, не
пишешь тесты и не правишь сборку. Твоя работа: понять, чего хочет человек, узнать у
скрипта следующее действие, запустить ОДИН скилл и коротко отчитаться.

**Автономная версия.** Запрос приходит от терминального приложения, человека рядом нет.
Вопросов не задавай и ответа не жди: где нужна развилка - решение по правилам скиллов
(`references/core-rules.md`, правило 8). Исключение одно - вопросы разметки на Этапе 2
карты: их выводит `migration-map` блоком `<<<PVATF-QUESTIONS`, ответы приносит приложение.

## Когда использовать / когда не использовать

Использовать в начале каждого чата по миграции, окружению и генерации автотестов PVATF.
Не использовать для вопросов о коде, не связанных с этими процессами.

## Предусловия

- Запуск из корня проекта автотестов (там, где `.gigacode/`), Python 3.8+.
- Агенты набора `pvatf-*` в `.gigacode/agents/`: человек копирует их вместе со скиллами (папка `agents/` набора). Нет агентов - скрипт шага 2 печатает `нет агентов`.

Миграция: сначала прочитай `references/core-rules.md` - общие правила миграции. Окружение и
генерация: правила - `references/autotest-rules.md` (их читает запущенный скилл).

## Шаги

**Скрипты этого скилла лежат в `.gigacode/skills/orchestrator/scripts/`.** Команды ниже - готовые:
копируй и запускай как есть, из корня проекта (там, где `.gigacode/`); нужен
Python 3.8+ (команды `python3 ...`; на Windows, где нет `python3`, - `python ...` или `py -3 ...`). Скрипта по этому пути нет (скиллы установлены в другое место) -> найди его один
раз: `find . ~/.gigacode -path "*orchestrator/scripts/*.py" 2>/dev/null | head -3` - и подставляй
найденный каталог. Скрипт упал с ошибкой -> покажи ошибку в чате, дальше - по таблице
«Обработка ошибок»; молча пропускать скрипт нельзя.

### Шаг 2 - Спроси скрипт, что делать

### Шаг 3 - Запусти один скилл и дождись его конца

Вызови выбранный скилл через механизм вызова скиллов. С этого момента работаешь по SKILL.md
этого скилла: его правила главнее этого файла. Когда скилл закончил - второй скилл в этом
чате не запускай.

**Исключение - окружение перед генерацией.** Аргумент Шага 2 был `autotest ...` (генерация по
ТК, артефакту, очереди), ДЕЙСТВИЕ было `env-init`, `env-setup` или `env-setup <ключ>`, и
`env-check` закончил с окружением `ok` / `warning` (с ключом - строка `ОКРУЖЕНИЕ ТК: готово`) ->
не останавливайся: снова Шаг 2 с тем же аргументом и запусти скилл из нового ДЕЙСТВИЯ. Так - не
больше 2 раз за чат. Окружение не настроилось (`failed`, `ОКРУЖЕНИЕ ТК: не готово`) -> покажи
итог `env-check` и закончи: генерацию на ненастроенном окружении не запускай.

Нельзя: «Окружение не настроено, напишите /orchestrator настрой окружение» в ответ на просьбу
сгенерировать автотест. Нужно: ДЕЙСТВИЕ `env-setup BNK-T101` -> `env-check` подключил модули и
сервисы -> Шаг 2 -> ДЕЙСТВИЕ `autotest-gen BNK-T101` -> генерация в этом же чате.

## Контракт «вход -> выход»

Вход: запрос после `/orchestrator`. Выход: две строки вывода скрипта дословно, результат
одного запущенного скилла и итоговый ответ по шаблону ниже. Очередь `QUEUE.md` меняется только через `autotest_queue.py`.

## Обработка ошибок

| Что случилось | Что делаешь |
|---------------|-------------|
| Скрипт скилла без компиляции и без MCP-вызова не закончил работу за 120 секунд | Прерви вызов, покажи вывод дословно, дальше не иди. Повторно не запускай |
| Скрипт шага 2 упал или вывел не `ДЕЙСТВИЕ:` | Покажи вывод дословно. Скиллы не запускай, состояние сам не разбирай |
| Запущенный скилл закончился ошибкой | Покажи его итог; второй скилл в этом чате не запускай |

## Итоговый ответ человеку

Коротко:
- что было на входе и какой скилл запущен;
- что он сделал (этап карты / юнит и его статус);
- прогресс: `done` X из N юнитов;
- что осталось на человеке (строки `решить человеку`, решения из раздела 6 карты; пуш не делается);
- что дальше: **«Откройте новый чат и напишите: `/orchestrator Продолжи миграцию`»**.
