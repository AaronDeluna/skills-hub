## Критерии приёмки
1. Каждый шаг ТК - шаг теста с комментарием `// Шаг <n>: <действие>`; служебные шаги - без кода.
2. Каждый ожидаемый результат - проверка в коде по design.md, раздел 13.
3. `@TmsLink("<ключ>")` на тест-методе (ТК нет - без `@TmsLink`).
4. Компиляция тестов `<команда компиляции из ENV.json>` - без ошибок.
5. `at_tools.py check <ключ>` - ИТОГ: находок 0.
6. `at_tools.py run <ключ>` - РЕЗУЛЬТАТ: passed; тест запускается последней задачей, без вопроса человеку. Не прошёл - отчёт RUN.md человеку, изменение без passed архивирует только человек.
