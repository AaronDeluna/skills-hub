Путь: `.gigacode/data/migration/MIGRATION-REVIEW.md`. Заполняй только `<...>`. Заголовки не
меняй. Новый круг проверки дописывается новым разделом «Круг <n>» в конец файла, старые
круги не стираются.

- проверяемых файлов: <n>
