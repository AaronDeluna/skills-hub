# Статус миграции

Часть скилла `orchestrator`. Открывай, только когда SKILL.md направил сюда.

Прочитай таблицу «4. Юниты работ» и выведи:
- сколько юнитов всего / `done` / `in-progress` / `todo` / `blocked`;
- по фазам: какая фаза сейчас идёт;
- какая технология сейчас мигрируется и какие ещё впереди (по порядку из карты), какие
  остаются на старой реализации (`keep`);
- если идёт юнит технологии (`tech`, статус `in-progress`): сколько его подшагов сделано и
  какой следующий - `grep -E "^\| S-[0-9]+" .gigacode/data/migration/units/M-<nnn>.md`
  (только таблица подшагов, карточку целиком не читай);
- какой юнит следующий;
- открытые вопросы (раздел 6 карты), если есть - и что миграция стоит, пока на них нет ответа;
- строки `решить человеку` из раздела «5. Входящие» - сколько и какие (`grep -n "решить человеку" .gigacode/data/migration/MIGRATION-MAP.md`).

## Какие файлы что хранят

Всё в одной папке в корне мигрируемого проекта: `.gigacode/data/migration/`

| Файл                       | Что в нём                                                         | Кто пишет        |
|----------------------------|-------------------------------------------------------------------|------------------|
| `MIGRATION-MAP.md`         | Карта: паспорт проекта, что на что меняем, список юнитов и их статусы, журнал сессий, «что уже изменилось» | `migration-map`, `migration-step` |
| `ARCHITECTURE.md`         | Архитектурный план: слои, пакеты и классы проекта после миграции, какой класс за что отвечает | `migration-map`, `migration-step` |
| `CONNECTIONS.md`           | Реестр подключений: адреса, учётные данные, сертификаты, топики, переменные окружения из проекта и куда они переезжают в настройках фрейма | `migration-map`, `migration-step` |
| `doc-notes/<технология>.md` | Конспект документации фрейма из MCP по технологиям: вопросы, ответы, какими формулировками спрашивали | `migration-map`, `migration-step` |
| `units/M-<nnn>.md`         | Карточка одного юнита: файлы, шаги, док-основание, журнал выполнения | `migration-map`, `migration-step` |
| `inventory/<модуль>.md`    | Сырые результаты инвентаризации по модулям                        | `migration-map`  |
| `MIGRATION-REVIEW.md`      | Отчёт проверки миграции целиком: находки по кругам, вердикт | `migration-review` |
| `archive/MAP-ARCHIVE.md`  | Архив карты: выполненные юниты, закрытые вопросы, старый журнал - то, что убрано из карты при сжатии | `orchestrator` |
| `review/M-<nnn>.md`        | Отчёт ревью мигрированного кода: находки сабагентов и что с ними сделано | `migration-step` |
| `inventory/technologies.md` | Отчёт сабагента: какие технологии использует проект (если пользователь не назвал их сам) | `migration-map`  |
